# GD Store — frontend

React 18 + Vite + React Router + TanStack Query + Zustand. Сохранён JavaScript/JSX-стек исходного репозитория.

## Запуск

```sh
cd frontend
npm ci
npm run dev
```

По умолчанию работает демонстрационная витрина, Django не требуется. Изображения хранятся локально. Демо-корзина существует только в памяти и очищается при обновлении страницы. Реальная авторизация и оплата в демо отключены.

## Подключение Django

Скопируйте `.env.example` в `.env.local`:

```dotenv
VITE_DEMO_MODE=false
VITE_API_BASE_URL=/api/v1
```

Перезапустите Vite. Dev-прокси направляет `/api` на `http://localhost:8000` (настройка в `vite.config.js`). Для другого сервера задайте полный URL в `VITE_API_BASE_URL` и разрешите CORS на Django. Эти переменные публичные, секреты в них хранить нельзя.

API-клиенты в `src/api/` сохраняют маршруты текущего Django-проекта. Демо-режим выбирается явно: ошибка реального API не подменяется демонстрационными данными.

| Экран      | API                                                                           |
| ---------- | ----------------------------------------------------------------------------- |
| Каталог    | GET `/catalog/games/`, параметры `search`, `genres__slug`, `ordering`, `page` |
| Жанры      | GET `/catalog/genres/`                                                        |
| Игра       | GET `/catalog/games/:slug/`                                                   |
| Корзина    | GET/POST `/store/cart/`, POST body `{game: id}`                               |
| Удаление   | DELETE `/store/cart/:id/`                                                     |
| Заказ      | POST `/store/cart/checkout/`                                                  |
| Библиотека | GET `/library/`                                                               |
| Вход       | POST `/auth/login/`                                                           |

Каталог и корзина ожидают `{results: [...]}`. Каталог использует `count`, `next`, `previous`. Жанры поддерживают массив и пагинированный ответ. Поля игры: `id`, `slug`, `title`, `cover_image`, `price`, `discount_percent`, `final_price`, `genres`; детали дополнительно используют `short_description`, `description`, `screenshots`. Цены выводятся в UAH, как в исходном проекте. Карточки жанров строятся из API, не из жёстко заданных slug.

Текущие подборки используют записи текущей страницы каталога. Скидки фильтруются на клиенте в рамках этой страницы. Для полноценных глобальных акций и редакционных подборок команде нужен соответствующий контракт API. Платёжный провайдер, refresh JWT, регистрация и профиль остаются отдельными следующими этапами существующего проекта.

## Дизайн и адаптивность

Референс: [Slush, desktop Main](https://www.figma.com/design/hBxLb01yMKYFPLlKgoj93q/Slush-project?node-id=1157-810).

Сохранены тёмная морская палитра, бирюзовые акценты, розовые скидки и структура игровых подборок. Изменены бренд, отступы, карточки, расположение рекомендаций и блок жанров. Общие токены и сетки находятся в `src/index.css`, переиспользуемые элементы — в `src/components/`.

Десктоп: минимум 960 CSS px; компактная сетка до 1200 px, стандартная от 1200 px, увеличенная от 1700 px; контейнер ограничен 1544 px. Ниже 960 px сохраняется десктопная ширина. Мобильная версия не входит в этап. Есть клавиатурный фокус, skip-link, reduced-motion и состояния загрузки/ошибок/пустых результатов.

Первые экраны: витрина, каталог/поиск, карточка игры, корзина, пустая библиотека и вход. Остальные экраны большого Figma-файла пока не реализованы.

## Проверка

```sh
npm run lint
npm test
npm run build
```

Тесты проверяют поиск, фильтр жанров, сортировку, ошибочный slug, дубликаты и удаление в корзине и запрет демо-платежей. Визуальное браузерное тестирование и проверка с работающим Django в этот этап не включены.

## Изображения

Обложки и кадр Cyberpunk получены через официальный Steam Store API для демонстрации. Ссылки на страницы-источники: `src/data/asset-sources.json`. Это не передача прав: перед коммерческим запуском замените материалы на согласованные с правообладателями. Демо-цены и скидки вымышлены.
