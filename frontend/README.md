# GD Store — современный фронтенд

Самостоятельный React-фронтенд на основе предыдущего GD Store. Бэкенда и базы данных нет.
Все действия работают в локальном деморежиме. Никакие запросы к Django или MSSQL не выполняются.

## Запуск

Нужен Node.js 22.12+ (ветка 22 LTS) и npm.

```powershell
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. Не открывайте index.html двойным кликом.

```powershell
npm run lint
npm test
npm run build
npm run preview
```

Для статического хостинга загрузите dist после сборки. Настройте перенаправление всех путей на index.html для React Router.

## Что работает

- Магазин: поиск, жанры, сортировка, скидки, карточка игры, желаемое.
- Корзина и подтверждение демозаказа: игры появляются в библиотеке без оплаты.
- Библиотека: поиск, сортировка и витрина демонстрационного прогресса.
- Профиль: имя, описание, страна, статус, аватар до 500 КБ, цвет и обложка.
- Витрина игр, достижения и активность игрока.
- Друзья: поиск по имени/логину, заявки, принятие, отмена, удаление и блокировка.
- Чат между локальными друзьями с сохранением истории.
- Обсуждения: создание, редактирование своей темы, ответы и удаление своей темы.
- Мастерская: карточки, фильтры, подписки, создание, редактирование и удаление своих работ.
- Отзывы владельцев игр, локальная регистрация и переключение демопрофилей.
- Настройки компактности и анимаций, сброс данных с подтверждением.

## Как проверить друзей и чат

1. По умолчанию выбран Karim. Откройте Друзья или нажмите Nova в боковой панели.
2. Отправьте сообщение Nova.
3. В Настройках выберите Nova. Откройте переписку с Karim и ответьте.
4. Вернитесь в Karim через Настройки — ответ останется в истории.
5. Для заявки найдите Danya, отправьте заявку, переключитесь на Danya и примите её в разделе Заявки.

Все профили — локальные демонстрационные записи, доступные пользователю этого браузера.
Нет настоящей авторизации и паролей. Активный профиль общий для вкладок одного адреса сайта.
Данные сохраняются в localStorage под ключом gd-store-studio-v1. Очистка данных браузера удалит их.
Это не сетевой чат: другой компьютер или браузер не получит ваши сообщения.

## Структура

src/App.jsx — маршруты.
src/studio/Studio.jsx — общий интерфейс, магазин, карточки и базовые компоненты.
src/studio/Personal.jsx — профиль, библиотека, корзина, карточка игры, отзывы.
src/studio/Social.jsx — друзья, чат, обсуждения и мастерская.
src/studio/Account.jsx — демопрофили, регистрация, настройки и заказы.
src/demo/model.mjs — демонстрационные данные и операции над ними.
src/demo/context.jsx — состояние React, сохранение и синхронизация вкладок.
src/index.css — дизайн и адаптация размеров.
public/art — три оригинальные обложки, созданные для проекта.
tests — тесты сценариев и рендера маршрутов.

## Подключение будущего бэкенда

Слой src/demo отделён от интерфейса. Замените операции act и загрузку state в провайдере
на API-адаптер с асинхронными состояниями загрузки и ошибок. Для чата понадобится сервер
и WebSocket/SSE или опрос API; для авторизации — серверная проверка сессии.
Не используйте демопереключение профилей как настоящую авторизацию.
У новых экранов есть UI-состояния, но готового API-адаптера в этой версии нет.

## Ограничения

Все игры, оценки, часы, уровни, достижения и счётчики мастерской — вымышленные демоданные.
Мастерская сохраняет только метаданные и имя выбранного ZIP, не его содержимое.
Нет оплаты, установки/запуска игр, DRM, голосового чата и сетевой синхронизации пользователей.
Основной дизайн рассчитан на ПК; добавлена перестройка элементов при уменьшении окна.
Проверены 13 тестов, включая рендер 18 маршрутов, линтер и сборка. Браузерные клики и визуальная QA не выполнялись.
