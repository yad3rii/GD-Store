# GD Store — современный фронтенд

Самостоятельный React-фронтенд на основе предыдущего GD Store. Бэкенда и базы данных нет.
Все действия работают в локальном деморежиме. Никакие запросы к Django или MSSQL не выполняются.

## Запуск

Нужен Node.js 22.12+ (ветка 22 LTS) и npm.

```powershell
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. Не открывайте index.html двойным кликом.

```powershell
npm run lint
npm test
npm run build
npm run preview
```

Для статического хостинга загрузите dist после сборки. Настройте перенаправление всех путей на index.html для React Router.

## Что работает

- Магазин: поиск, жанры, сортировка, скидки, карточка игры, желаемое.
- Корзина и подтверждение демозаказа: игры появляются в библиотеке без оплаты.
- Библиотека: поиск, сортировка и витрина демонстрационного прогресса.
- Профиль: имя, описание, страна, статус, аватар до 500 КБ, цвет и обложка.
- Витрина игр, достижения и активность игрока.
- Друзья: поиск по имени/логину, заявки, принятие, отмена, удаление и блокировка.
- Чат между локальными друзьями с сохранением истории.
- Обсуждения: создание, редактирование своей темы, ответы и удаление своей темы.
- Мастерская: карточки, фильтры, подписки, создание, редактирование и удаление своих работ.
- Отзывы владельцев игр, локальная регистрация и переключение демопрофилей.
- Настройки компактности и анимаций, сброс данных с подтверждением.

## Как проверить друзей и чат

1. По умолчанию выбран Karim. Откройте Друзья или нажмите Nova в боковой панели.
2. Отправьте сообщение Nova.
3. В Настройках выберите Nova. Откройте переписку с Karim и ответьте.
4. Вернитесь в Karim через Настройки — ответ останется в истории.
5. Для заявки найдите Danya, отправьте заявку, переключитесь на Danya и примите её в разделе Заявки.

Все профили — локальные демонстрационные записи, доступные пользователю этого браузера.
Новые учётные записи используют локальный пароль и код восстановления. Это не серверная авторизация. Активный профиль общий для вкладок одного адреса сайта.
Данные сохраняются в localStorage под ключом gd-store-studio-v1. Очистка данных браузера удалит их.
Это не сетевой чат: другой компьютер или браузер не получит ваши сообщения.

## Ограничения

Все игры, оценки, часы, уровни, достижения и счётчики мастерской — вымышленные демоданные.
Мастерская сохраняет только метаданные и имя выбранного ZIP, не его содержимое.
Нет оплаты, установки/запуска игр, DRM, голосового чата и сетевой синхронизации пользователей.
Основной дизайн рассчитан на ПК; добавлена перестройка элементов при уменьшении окна.
Проверены 53 теста, включая рендер 33 маршрутов, линтер и сборка. Браузерные клики и визуальная QA не выполнялись.


## Новое: управление, оформление покупки и подбор игр

- Панель `/admin` доступна профилю Karim через «Управление сайтом» в боковой панели.
- Администратор блокирует пользователей с указанием причины и снимает блокировку.
- Заблокированному профилю недоступны сообщения, публикации, изменения и покупки.
- Можно скрывать и восстанавливать темы и работы, закрывать обсуждения для ответов.
- Скрытый материал недоступен обычному профилю, в том числе по прямой ссылке.
- Объявление администратора отображается над страницами; журнал сохраняет последние 100 действий.
- `/checkout`: тестовая карта, быстрый демозаказ, подарок принятому другу и промокод PLAY10 (−10%).
- Реквизиты только тестовые: 4242 4242 4242 4242, срок 12/30, CVC 123. Не вводите реальные данные.
- Поля карты находятся только в состоянии формы, не записываются в localStorage и не отправляются.
- Реального списания нет. Чек показывает фактически списанную сумму 0 ₴.
- `/compare`: сравнение до трёх игр по цене, оценкам, жанру и другим свойствам.
- `/discover`: подбор случайной игры по настроению, бюджету и наличию в библиотеке.
- Старые данные автоматически обновляются до версии 3 без очистки localStorage.

Новые модули: src/studio/Admin.jsx, Checkout.jsx, Discovery.jsx и src/demo/extras.mjs.
Роли и блокировки в этой версии демонстрационные. Реальную авторизацию и модерацию должен
проверять будущий сервер: пользователь браузера может менять localStorage и переключать профили.


## Игровые вечера, уведомления и коллекции

- «Игровые вечера» в боковой панели: название, игра, дата и местное время, описание, приглашённые друзья.
- Приглашать можно принятых и незаблокированных друзей. Приглашения видны только участникам.
- Участник отвечает «Буду играть», «Не смогу» или «Пока не знаю»; организатор получает уведомление.
- Изменить или отменить вечер может организатор. При изменении планов приглашённые получают уведомления.
- Прошедшие и отменённые события находятся в архиве. Это планировщик, без запуска игр и звонков.
- Колокольчик в верхней панели открывает уведомления: заявки, сообщения, ответы, подарки и события.
- Уведомления принадлежат конкретному профилю, отмечаются прочитанными отдельно или все сразу.
- Библиотека → «Мои коллекции»: создание папок, имя, цвет, выбор игр из собственной библиотеки.
- Коллекции видит только владелец. Удаление коллекции не удаляет игры из библиотеки.
- Сохранённые данные версий 1 и 2 обновляются до версии 3 без очистки профилей, чатов и заказов.

Пример проверки: Karim создаёт вечер с Nova → в Настройках выбрать Nova → нажать колокольчик
→ открыть приглашение и выбрать «Буду играть» → вернуться к Karim и увидеть ответ.
Новые уведомления создаются при новых действиях; прошлые сообщения автоматически в центр не копируются.

Новые файлы: src/demo/social.mjs, src/studio/Events.jsx, Collections.jsx, Notifications.jsx,
tests/social.test.mjs. Реального сетевого сервера и внешних рассылок нет.


## Оформление, жалобы и локальный вход

- Полосы прокрутки скрыты; прокрутка колесом, тачпадом и клавиатурой сохранена.
- `/points-shop`: девять аватаров, баннеров и рамок. Каждый профиль получает 1000 демобаллов; купленные предметы можно применять и снимать.
- Жалоба на игрока находится в его профиле, на сообщение — кнопка флага рядом с входящим сообщением. `/admin` → «Жалобы»: решение с пояснением и отдельная блокировка.
- `/admin` → «Пользователи»: назначение и снятие прав других администраторов. Основной администратор Karim защищён от снятия роли.
- `/register`, `/login`, `/forgot-password`: регистрация, вход и восстановление по личному коду, показанному один раз после регистрации. Email используется как логин; письма не отправляются.
- Пароли и коды сохраняются только как проверочные хеши PBKDF2 с солью. Web Crypto требует localhost или HTTPS. Клиентская проверка не заменяет серверную защиту.
- Готовые демопрофили выбираются в настройках; новые записи открываются через форму входа.
- При покупке в подарок можно написать послание. Получатель увидит окно подарка, уведомление и историю `/gifts`. Игры сразу доступны в его локальной библиотеке.
- Для проверки подарка отправьте Karim → Nova, затем переключитесь на Nova в настройках. Для проверки жалоб отправьте Nova → Alex и откройте админку как Karim.
- Схема данных обновляется до версии 4 без удаления старых сообщений, заказов и профилей.

Новые экраны: `AuthScreen.jsx`, `Reports.jsx`, `Gifts.jsx`, `CosmeticsShop.jsx`.
Локальная логика: `src/demo/community.mjs`, `src/demo/auth.mjs`. При интеграции замените `account`, `act` и загрузку данных на серверные операции.


## Поиск напарников, витрина и награды
Поиск напарников /teammates: создание и редактирование объявлений, игра, язык,
время, 2–8 мест, фильтры, вступление, выход и закрытие набора организатором.
Организатор получает уведомление о новом участнике. Все данные локальные.
Витрина профиля: свой заголовок, до трёх игр из библиотеки в выбранном порядке.
Покупки: 1 демобалл за каждые полные 10 ₴ суммы после скидки.
За подарок награду получает покупатель. Бесплатные игры не дают баллов.
Баллы начисляются только за новые заказы; старые заказы не пересчитываются.
Награда показана при оформлении, после покупки и в истории заказов.
Проверено: 48 тестов, рендер 31 маршрута, ESLint, production-сборка.
Визуальные браузерные проверки не выполнялись. Коммит и push не выполнялись.

1. /support: обращения по покупке, аккаунту, жалобе или другому вопросу.

статусы «Открыто», «В работе», «Решено», повторное открытие администратором.

разрешение заявок. Ограничения действуют в локальном интерфейсе.

при входе или ручной проверке. В статичном каталоге автоматических скидок нет.
Кнопка примера создаёт явно помеченное демоуведомление, не меняя цену.
5. /points-history: начисления, расходы, фильтры и баланс.
Существующий баланс записан начальной строкой; новая история ведётся подробно.
